# Логотипы для карточек и плиток загрузчиков

Положите сюда PNG (лучше квадратные, прозрачный фон, от 256×256) с такими именами — они подхватятся сами, код менять не нужно:

| Файл | Где показывается |
|---|---|
| `modrinth.png` | карточка Modrinth |
| `curseforge.png` | карточка CurseForge |
| `custom-build.png` | карточка «Своя сборка» (любая картинка, например верстак) |
| `import.png` | карточка «Импорт из файла» |
| `microsoft.png`, `offline.png` | карточки в окне «Добавить аккаунт» |
| `fabric.png`, `quilt.png`, `forge.png`, `neoforge.png` | плитки загрузчиков в форме, в списке версий и в выпадающем списке |

Файла нет — показывается встроенная иконка (для загрузчиков — монограмма).
Используйте только те логотипы, на которые у вас есть право; условия использования знаков смотрите на сайтах проектов.
Файлы подключаются как ресурсы (`<Resource Include="Assets\Logos\*.png" />` в csproj): после добавления нужна пересборка.
